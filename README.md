# Zero Trust IAM Lab

## About This Project

This project demonstrates how to secure cloud resources using Zero Trust security principles and Identity and Access Management (IAM).

## Objectives

- Implement least-privilege access.
- Secure service accounts.
- Apply strong authentication practices.
- Monitor security events using cloud audit logs.
- Test and document unauthorized access attempts.
- Use Terraform to manage cloud infrastructure.

## Technologies

- Google Cloud Platform (GCP)
- Terraform
- Git and GitHub
- PowerShell
